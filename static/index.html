How to Use ALVEA

ALVEA transforms plain-text or structured operational descriptions into executive Mermaid.js Swimlane diagrams, live NetworkX graph analytics, an Executive Report, and a numbered Standard Operating Procedure (SOP) — exportable to PDF, Markdown, SVG, PNG HD, YAML, and JSON.

1. Quick Start

Every workflow in ALVEA flows through the same canonical pipeline:

  1. Write or paste your workflow in the Workflow Narrative box on the left (English or Spanish).
  2. Pick an engine: keep the default Native Python BPA Engine for instant 100% offline parsing, or choose a local LLM (Ollama / LM Studio) or free cloud provider.
  3. Press Ctrl + Enter (or click Generate Architecture). ALVEA compiles a typed ProcessGraph, renders the Swimlane diagram, calculates NetworkX metrics, and generates the Executive Report automatically.
  4. Refine & export: switch between Horizontal (LR) and Vertical (TD), toggle Highlight Critical Path, edit Mermaid live, or export to PNG HD, SVG, PDF, YAML, or JSON.

2. Writing Effective Workflows (Syntax Reference)

The Native Python Workflow Engine v3 understands four complementary input styles — and you can freely mix them:

Pattern Syntax Example Engine Behavior
Explicit Actor Risk Team: Review income [2h] Assigns the step to the Risk Team swimlane with a 120 min SLA weight.
Direct Handoff Customer -> API Gateway: Submit form [5m] Links Customer directly to API Gateway (classified as a system cylinder node).
Multi-Branch Decision If amount > 10000, Finance approves. Else if amount > 1000, Manager approves. Otherwise, System auto-approves. Groups all 3 branches onto a single diamond gateway with labeled outgoing edges.
Parallel Fork / Join In parallel: followed by bulleted items (- Legal: Draft contract / - IT: Provision access) or Meanwhile, ... Inserts a teal hexagon Parallel Split, parallel edges, and automatic Sync / Join convergence.
Wait / SLA States Wait 24h for vendor confirmation Renders an amber wait flag node and surfaces SLA optimization recommendations if on the critical path.
Rework Loops If invalid, returns to Requester to fix and resubmit. Draws a dotted feedback edge (-. "Rework" .->) and registers a cycle in NetworkX.

Semantic Node Shapes

ALVEA automatically classifies steps into 9 visual BPMN-inspired types:

  • Start / End Success / End Reject: green & red rounded capsules.
  • Task: clean neutral slate box for human/department activities.
  • System: blue database/service cylinder for APIs, ERPs, bots, and automated checks.
  • Subprocess: indigo double-bordered box for nested procedures (e.g. KYC, background checks).
  • Wait: amber flag shape for delays, queues, and SLA timers.
  • Decision: yellow diamond for conditional branching.
  • Parallel (Fork / Join): teal hexagon for concurrent execution tracks.

3. Prompting Design Best Practices

Whether you use ALVEA's instant offline Python engine or a cloud/local LLM (Gemini, Groq, OpenRouter, Ollama, or a Custom API), how you phrase your workflow dramatically improves swimlane accuracy, critical-path timing, and SOP clarity.

The 5 Golden Rules for High-Precision Workflow Prompts

  1. Name Roles Explicitly (One Actor per Step): Start clauses with who performs the action (e.g., Applicant: Submit form or ERP System: Validate stock) instead of passive voice ("the form is checked"). Consistent role names prevent duplicate swimlanes.
  2. Use Action Verbs & Specific Systems: Distinguish human tasks ("Manager approves") from automated services ("Billing API generates invoice") so ALVEA accurately computes your Automation Ratio and draws System cylinders.
  3. Write Exhaustive Branches (If / Else If / Otherwise): Always state both the happy path and the rejection/escalation path (e.g., If score >= 700, Underwriting approves. Otherwise, System notifies rejection.).
  4. Declare Concurrency & Rework Loops Clearly: Use In parallel: with bullets for simultaneous tracks, and returns to [Role/Step] for correction loops so NetworkX detects cycles and the SOP cross-references exact step numbers.
  5. Embed SLA Durations & Terminal States: Attach timings like [15m], [4h], or [2d] and state explicit end milestones ("Order Fulfilled", "Ticket Closed") so NetworkX computes real cycle times in minutes.

Weak Prompt vs. High-Precision Prompt

Weak (Ambiguous) Strong (Architecture & SOP Ready)
"A request comes in, gets reviewed, maybe approved or sent back, and then finished." Requester -> Portal: Submit request [10m]. Manager: Review budget [2h]. If approved, in parallel: - Finance: Issue PO [1h] - IT: Provision license [30m]. Then Portal: Notify completion. If incomplete, returns to Requester to fix. Otherwise, Manager: Reject and archive.

Engine-Specific Prompting Tips

  • Native Python Engine v3 (Offline): Prefers crisp sentences, bulleted In parallel: blocks, explicit Actor: Action [duration], and clear If / Else if / Otherwise clauses.
  • Cloud & Local LLMs (Gemini, Groq, Ollama, Custom APIs): Excel at distilling long meeting notes, raw policies, or messy email threads into clean Swimlanes. Tip: add one opening line stating Process Title: ... and Main Roles: ... at the top of messy notes for even tighter output.

5. NetworkX Graph Intelligence Metrics

  • Efficiency Grade (A+ to C): composite operational score combining automation coverage, inter-lane handoff friction, rework cycles, complexity, and structural anomalies.
  • Cyclomatic Complexity (M = E - N + 2P): measures decision branching density (Low ≤ 4, Moderate 5–10, High > 10).
  • Critical Path: longest weighted path over the cycle-condensed DAG. When you include explicit step durations (e.g. 30m, 2h, 1d), ALVEA computes total estimated cycle time in minutes; otherwise it uses relative operational weights.
  • Primary Bottleneck: highest-risk node ranked by NetworkX betweenness centrality, degree, incident cross-lane handoffs, manual effort, and wait penalties.
  • Handoffs & Automation: percentage of transitions crossing swimlane boundaries and percentage of automated/system steps.
  • Cycles & Structural Anomalies: detects rework loops, orphan nodes, unreachable steps, dead ends without terminal nodes, and incomplete decisions (< 2 branches).

6. Executive Report, SOP Document, Shortcuts & Exports

ALVEA automatically generates two complementary formal documents for every workflow: the Executive Report (for management diagnostics, bottlenecks, and ROI recommendations) and the SOP Document (an ISO-style Standard Operating Procedure with topological step numbering, parallel track indexing like 3a / 3b, role ownership, decision routing, rework loop references, and SLA controls).

Editing syntax in the Mermaid Code tab and clicking Apply to Diagram (or Ctrl + S) sanitizes the syntax, re-parses the diagram back into a ProcessGraph, and recalculates NetworkX metrics, the Executive Report, and the SOP Document automatically.

  • PNG HD (3x) & SVG: crisp vector and high-resolution raster diagrams with zero foreignObject issues.

7. Security & Privacy Architecture

  • Zero Server-Side Key Persistence: API keys live in browser RAM by default (optional sessionStorage), are sent only via HTTP headers (never in URL query strings), wrapped in SecretStr, and automatically redacted from logs.
  • SSRF Protection: cloud providers are pinned to an HTTPS-only allowlist; local LLMs are restricted to loopback (127.0.0.1 / localhost / ::1) with DNS rebinding, IMDS (169.254.169.254), and redirect blocking.
  • Strict XSS & CSP Defense: Content-Security-Policy: script-src 'self', Mermaid securityLevel: "strict" with htmlLabels: false, unconditional stripping of click/%%{init} directives, and innerHTML-free rendering.
  • 100% Offline Operation: bundled Mermaid.js + local Python engine + NetworkX + ReportLab run completely offline.
